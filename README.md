# All Queens Chess

H5 2.5D browser edition of ThinkFun’s *All Queens Chess*.

## Play

```bash
npm install
npm run dev
```

Open the printed local URL (default `http://localhost:5173`).

## Modes

- **Local** — two players on one device
- **vs AI** — play against a simple threat-aware opponent

Players choose who moves first. Queens move as in chess but **cannot capture**. First to align **four** queens in a contiguous line wins.
